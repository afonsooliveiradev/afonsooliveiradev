## 🚀 Sobre mim

Minha trajetória profissional começou em operações, logística e área comercial. Com o tempo, passei a atuar cada vez mais com análise de desempenho, indicadores, governança, melhoria contínua, riscos e automação.

Hoje estou direcionando essa experiência para Tecnologia, com foco em construir soluções que conectem:

```text
Negócio
  ↓
Processos
  ↓
Dados
  ↓
Automação
  ↓
Software
  ↓
Produto Digital
```

Meu diferencial está justamente nessa interseção: entender o problema operacional, estruturar o processo, analisar os dados e transformar isso em uma solução tecnológica.
